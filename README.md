# Договор на бит — форма заполнения

Два договора на бит Scame, которые заполняются прямо в браузере
и выгружаются в PDF или DOC:

- **Полные права** — договор об отчуждении исключительного права (эксклюзив);
- **Безлимитная аренда** — лицензионный договор, простая неисключительная
  лицензия: бит используется без лимитов, права остаются у Scame,
  «prod. by Scame» обязателен. Галочка TRACKOUT добавляет в договор стемы.

На главной выбирается вид договора. Прямые ссылки: `#full` и `#lease`.

**Открыть:** https://scamemusic.github.io/dogovor/

## Что внутри

`index.html` — один самодостаточный файл. Бэкенда нет, базы нет: данные
вводятся прямо в текст договора и остаются в браузере посетителя. Никуда
не отправляются и нигде не сохраняются.

## Как заполнять

Нажать на подсвеченное место в тексте и вписать данные. Красное — ещё не
заполнено, жёлтое — заполнено, серое — считается само.

Само подставляется: сегодняшняя дата в шапке и под подписями, сумма
прописью с падежами, «рубль / рубля / рублей», «Фамилия И. О.» в строке
подписи. Поля, которые встречаются в договоре дважды — ФИО, паспорт,
адрес, название бита — синхронизированы между собой.

Счётчик сверху показывает, сколько полей осталось.

## Выгрузка

| | |
|---|---|
| **Скачать PDF** | 8 страниц A4, вёрстка как у бумажного оригинала |
| **Скачать DOC** | открывается в Word и Google Docs, текст редактируется |

Имя файла собирается из названия бита и покупателя.

## На телефоне

Ввод такой же — прямо в текст. Кнопки `−`, `+` и «По ширине» меняют масштаб
листа; при открытии договор вписывается по ширине экрана.

## Приватность

Страница закрыта от поисковых систем: `robots.txt` запрещает обход, в разметке
стоит `<meta name="robots" content="noindex,nofollow,noarchive">`. Репозиторий
публичный (иначе GitHub Pages не работает на бесплатном плане), поэтому ссылку
всё же стоит давать только адресно.

## Обновление

Исходник живёт в проекте как `Форма-договора.html`. После правок:

```bash
cp ../Форма-договора.html index.html
git add index.html && git commit -m "Обновление формы" && git push
```

GitHub Pages пересобирается сам за минуту.
